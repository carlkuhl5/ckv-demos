This is a preview. The admin is part of the ongoing operating plan in the PRD, not the one-off site build — because membership records, ticketing, giving, the raffle, and the competition are software the organisation depends on daily rather than pages that ship and sit. Which operating plan the ALO selects determines which of these systems are active at launch; the requirements are specified in full either way (PRD Sections 07–10).
